Hello, I am a software automation developer. Currently, my two former positions are vastly different in field but show how integral software interaction is with every area of modern life.

I enjoyed working with forensic video parsing software that uses FFMPEG converter commands combined with a proprietary file parser. Initially, the compute-heavy video conversions required on-premises hardware but using cloud computing, video conversion requests can be queued in simultaneously running 'pods' and video conversions in an online environment, scalable across the globe.

I equally enjoyed creating custom Windows apps and Spreadsheet scripts, using intuative tools like Microsoft's Power Platform. This service comes with Microsoft 365 to help anyone create 'Flows' to automate repetitive tasks. With only a few lines of code, API calls give Power Platform an incredible amount of potential for personal, small, or large businesses.

My goal now is to use the advantages of cloud computing & modern automation tools to streamline existing software interaction, or to construct new software to stay on top of growing areas in one's business or projects. I'm eager to help!
